# Yaşar Üniversitesi Öğrenci Oryantasyon Sistemi

Yaşar Üniversitesi'ne yeni katılan öğrencilerin oryantasyon sürecini planlamak, yönetmek ve takip etmek için geliştirilen sistem.

## Amaç

- Yeni öğrencilere kampüs, akademik birimler ve öğrenci hizmetleri hakkında bilgi sunmak
- Oryantasyon etkinliklerinin programını ve katılımını yönetmek
- Öğrencilerin oryantasyon sürecindeki ilerlemesini takip etmek

## Durum

Proje başlangıç aşamasındadır.
